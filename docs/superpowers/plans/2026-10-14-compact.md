# Compact frontend implementation plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan inline, with one fresh whole-branch reviewer.

**Goal:** Ship a reversible compact frontend and public project documentation/examples/site.

**Architecture:** `pact/compact.py` translates source to the existing IR. The loader recognizes the version header; the CLI adds explicit format conversion. Static site generation builds from validated examples.

**Tech Stack:** Python 3.10+, Node 20+, WebAssembly, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-14-compact.md`.

## Global Constraints

No new runtime dependencies; existing checked execution semantics and 1 MiB source limit remain. No token-efficiency claim without tokenizer measurements. Existing public repository supplied by user is the publication target.

## Review Focus

Duplicate keys/IDs must never silently overwrite. Invalid nesting must produce diagnostics. Quoted text containing delimiters must survive. Optional empty operand fields must roundtrip. Source conversion must not bypass semantic validation.
