# Efficiency benchmarks

`python3 -m benchmarks.source_sizes` reports UTF-8 byte sizes and validates equivalent sources. Bytes are not tokens.

Future runs must record tokenizer/model/version, prompts, tools and tasks. Measure all tokens including tool responses, repair cycles, cost and successful final behavior. Compare minified JSON, compact PACT and conventional languages with equivalent selective tools; report multiple runs including failures.

Suggested tasks: change jump height, fix collision, add state, update a sprite, diagnose a denied effect. Executable acceptance tests judge results independently of agent assertions.
